# チェックポイント削除

スクリプトはこの SKILL.md から見て `../../scripts/` にある（`<この SKILL.md のディレクトリ>/../../scripts/`）。プラグインはインストール時にコピーされるので、パスを推測せずこのファイルの位置から解決すること。

## 手順

1. まず以下のコマンドでチェックポイント一覧を取得してください：
   ```
   ../../scripts/list-checkpoints.sh
   ```

2. 一覧をユーザーに表示し、削除方法を尋ねてください：
   - **特定のチェックポイントを削除**: 番号またはIDで指定
   - **Codex作成のチェックポイントをすべて削除**: リネームされたものは保護されます
   - **すべてのチェックポイントを削除**: 他のクライアント（Claude Code、VS Code 拡張、OpenCode）が作ったものも消えます
   - **指定日数より古いチェックポイントを削除**: お気に入りは保護されます

3. ユーザーが選択したら、**削除対象と件数を明示して確認を取ってから**以下のいずれかのコマンドを実行してください：

   特定のIDを削除する場合：
   ```
   ../../scripts/delete-checkpoints.sh --ids <id1> [id2 ...]
   ```

   Codex作成のチェックポイントをすべて削除する場合：
   ```
   ../../scripts/delete-checkpoints.sh --codex
   ```

   すべてのチェックポイントを削除する場合：
   ```
   ../../scripts/delete-checkpoints.sh --all
   ```

   指定日数より古いチェックポイントを削除する場合：
   ```
   ../../scripts/delete-checkpoints.sh --older-than <days>
   ```

## 注意事項
- 削除はソフトデリートです（`.deleted` ファイルにIDを追加）
- 削除後もチェックポイントデータ自体はシャドウリポジトリに残ります
- `--all` や `--codex` を実行する前に、必ずユーザーに確認してください
- 削除対象の件数をユーザーに伝えてから確認を取ってください
