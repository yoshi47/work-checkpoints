# チェックポイント復元

スクリプトはこの SKILL.md から見て `../../scripts/` にある（`<この SKILL.md のディレクトリ>/../../scripts/`）。プラグインはインストール時にコピーされるので、パスを推測せずこのファイルの位置から解決すること。

## 手順

1. まず以下のコマンドでチェックポイント一覧を取得してください：
   ```
   ../../scripts/list-checkpoints.sh
   ```

2. 一覧をユーザーに表示し、復元したいチェックポイントの番号またはIDを尋ねてください。

3. ユーザーが選択したら、以下のコマンドで復元を実行してください：
   ```
   ../../scripts/restore-checkpoint.sh <checkpoint-id>
   ```

## 注意事項
- 復元すると現在のワークスペースのファイルが上書きされます
- 復元前に重要な変更がある場合は、ユーザーに確認してください
- スクリプトはカレントディレクトリのワークスペースを対象にします。復元はワークスペースのルートで実行してください
